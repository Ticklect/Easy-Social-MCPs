# Third-party notices

YouTube Easy v0.1.0 contains no third-party runtime packages and no copied third-party source code. Its runtime uses only Node.js built-ins and the browser's standard Chrome DevTools Protocol.

Public open-source YouTube automation projects were reviewed during design research. No code, selectors, fixtures, or packaged dependencies were taken from them. In particular, GPL/AGPL projects were not incorporated into this MIT-licensed project, and cookie-export or YouTube Data API approaches were deliberately not reused.
